# MakeSafe CT TSRA onboarding demo

Live site: https://demo-makesafe.tmx.llc

This repository contains the recovered MakeSafe onboarding demo as a static GitHub Pages site.

Pages:
- `index.html` — overview
- `status.html` — onboarding checklist with browser-local state
- `training.html` — training, certifications, and pay progression
- `gear.html` — roadside tools and safety links
- `links.html` — Zello, Towbook, forms, and company links

The public demo intentionally excludes private credentials, home-address data, Gmail message identifiers, and the signed contractor document.
